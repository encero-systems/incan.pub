# crates-io/globset

The crates.io package [globset](https://crates.io/crates/globset), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. Cross platform single glob and glob set matching. Glob set matching is the
process of matching one or more glob patterns against a single candidate path
simultaneously, and returning all of the globs that matched.
