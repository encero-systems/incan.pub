# crates-io/widestring

The crates.io package [widestring](https://crates.io/crates/widestring), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. A wide string Rust library for converting to and from wide strings, such as those often used in Windows API or other FFI libaries. Both `u16` and `u32` string types are provided, including support for UTF-16 and UTF-32, malformed encoding, C-style strings, etc.
