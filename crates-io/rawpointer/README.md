# crates-io/rawpointer

The crates.io package [rawpointer](https://crates.io/crates/rawpointer), adopted by [loaves.pub](https://loaves.pub) as Loaves. Extra methods for raw pointers and `NonNull<T>`.

For example `.post_inc()` and `.pre_dec()` (c.f. `ptr++` and `--ptr`),
`offset` and `add` for `NonNull<T>`, and the function `ptrdistance`.
