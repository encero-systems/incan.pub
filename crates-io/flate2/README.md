# crates-io/flate2

The crates.io package [flate2](https://crates.io/crates/flate2), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. DEFLATE compression and decompression exposed as Read/BufRead/Write streams.
Supports miniz_oxide and multiple zlib implementations. Supports zlib, gzip,
and raw deflate streams.
