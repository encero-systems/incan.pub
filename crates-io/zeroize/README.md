# crates-io/zeroize

The crates.io package [zeroize](https://crates.io/crates/zeroize), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. Securely clear secrets from memory with a simple trait built on
stable Rust primitives which guarantee memory is zeroed using an
operation will not be 'optimized away' by the compiler.
Uses a portable pure Rust implementation that works everywhere,
even WASM!
