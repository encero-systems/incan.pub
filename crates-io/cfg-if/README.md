# crates-io/cfg-if

The crates.io package [cfg-if](https://crates.io/crates/cfg-if), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. A macro to ergonomically define an item depending on a large number of #[cfg]
parameters. Structured like an if-else chain, the first matching branch is the
item that gets emitted.
