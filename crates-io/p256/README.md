# crates-io/p256

The crates.io package [p256](https://crates.io/crates/p256), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. Pure Rust implementation of the NIST P-256 (a.k.a. secp256r1, prime256v1)
elliptic curve as defined in SP 800-186, with support for ECDH, ECDSA
signing/verification, and general purpose curve arithmetic
