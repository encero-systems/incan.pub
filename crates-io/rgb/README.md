# crates-io/rgb

The crates.io package [rgb](https://crates.io/crates/rgb), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. `struct RGB/RGBA/etc.` for sharing pixels between crates + convenience methods for color manipulation.
Allows no-copy high-level interoperability. Also adds common convenience methods and implements standard Rust traits to make `RGB`/`RGBA` pixels and slices first-class Rust objects.
