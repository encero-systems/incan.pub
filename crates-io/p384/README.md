# crates-io/p384

The crates.io package [p384](https://crates.io/crates/p384), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. Pure Rust implementation of the NIST P-384 (a.k.a. secp384r1) elliptic curve
as defined in SP 800-186 with support for ECDH, ECDSA signing/verification,
and general purpose curve arithmetic support.
