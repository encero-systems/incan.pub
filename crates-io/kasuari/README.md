# crates-io/kasuari

The crates.io package [kasuari](https://crates.io/crates/kasuari), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. A rust layout solver for GUIs, based on the Cassowary algorithm.
A fork of the unmaintained cassowary-rs crate with improvments and bug fixes.
Kasuari is the indonesian name for the cassowary bird.
