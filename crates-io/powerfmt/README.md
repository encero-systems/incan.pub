# crates-io/powerfmt

The crates.io package [powerfmt](https://crates.io/crates/powerfmt), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. `powerfmt` is a library that provides utilities for formatting values. This crate makes it
    significantly easier to support filling to a minimum width with alignment, avoid heap
    allocation, and avoid repetitive calculations.
