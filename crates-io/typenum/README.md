# crates-io/typenum

The crates.io package [typenum](https://crates.io/crates/typenum), adopted by [incan.pub](https://github.com/encero-systems/incan.pub) as Loaves. Typenum is a Rust library for type-level numbers evaluated at
    compile time. It currently supports bits, unsigned integers, and signed
    integers. It also provides a type-level array of type-level numbers, but its
    implementation is incomplete.
