# crates.io packages incan.pub adopts beyond the download ranking (bake/top100, bake/top1000).
#
# `incan-pub adopt --additions adoption/additions.txt` adopts each at its newest stable version, with its dependency
# closure; a package already adopted at that version adopts nothing. An entry is a package name, then optionally
# `-default` when its consumers turn default features off and `+feature` for each feature they turn on. Adoption
# always plans the defaults as well, since admission holds every adoption to its default closure; the shape is what
# the package's bake shards build. `#` starts a comment.

# Ruff: Python parsing, syntax tree, semantic model, linting and formatting, as libraries.

ruff_python_ast
ruff_python_semantic
ruff_python_formatter
ruff_linter
